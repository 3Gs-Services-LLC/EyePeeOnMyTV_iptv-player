# EyePeeOnMyTV

A lightweight, minimal-chrome IPTV player for Windows 11 (x64), built with C# / .NET 8, WPF, and
[LibVLCSharp](https://github.com/videolan/libvlcsharp) (libVLC embedded in-process — no external VLC install
required).

The M3U/Xtream Codes playlist source and EPG (XMLTV) URLs are configured via **File > Settings** and
persisted to `%AppData%\EyePeeOnMyTV\settings.json`; nothing is hardcoded.

## Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (x64)
- Windows 11, x64

## Run in development

```bash
dotnet run -r win-x64
```

## Publish a single-file, self-contained x64 executable

```bash
dotnet publish -r win-x64 --self-contained true -p:PublishSingleFile=true -c Release
```

The resulting portable executable is written to:

```
bin\Release\net8.0-windows\win-x64\publish\EyePeeOnMyTV.exe
```

No separate VLC installation, .NET runtime, or installer is required on the target machine — copy
`EyePeeOnMyTV.exe` anywhere and run it.

| Play / Pause | Spacebar, or the play/pause button |
| Next / Previous channel | Up / Down, Page Up / Page Down, or the ⏭ / ⏮ buttons |
| Mute | `M`, or the mute button |

## Menu bar

A VLC-style menu bar (File / Playback / Audio / Video / Subtitle / Tools / Help) exposes the parts of
libVLC's public API that LibVLCSharp binds — playback controls, audio/video/subtitle track selection,
audio output device selection, a 10-band equalizer with libVLC's built-in presets, video adjustments
(contrast/brightness/hue/saturation/gamma), aspect ratio/crop/deinterlace, snapshots, external subtitle
files, opening a local file or arbitrary network stream URL, a media information panel, and a live
libVLC message log.

This intentionally does **not** attempt to reproduce VLC's full advanced Preferences dialog (the
"All" settings view) — that dialog is generated by walking libVLC's internal module/config
introspection system, which lives in `libvlccore` and isn't exposed through the public `libvlc.h`
API that LibVLCSharp (or any binding) can reach. Reaching it would mean depending on
undocumented, version-fragile internals. Likewise, Lua Extensions and the VLM streaming-server GUI
have no libVLC API surface to bind to at all, so they aren't present either.

Press `F1` (or Help > Shortcuts) for the full list of keyboard shortcuts.

## Settings (File > Settings, Ctrl+,)

- **IPTV Info** — either a plain M3U playlist URL, or Xtream Codes / Smarters-style credentials
  (server URL, username, password, optional port). Xtream Codes mode builds the standard
  `get.php?username=...&password=...&type=m3u_plus&output=ts` playlist URL from those credentials —
  the same approach VLC/TiviMate/etc. use — and feeds it through the same M3U fetch/parse path as
  plain M3U mode.
- **EPG Info** — zero, one, or many XMLTV URLs. All configured EPG sources are fetched and merged
  (by channel id) into a single guide.
- Saving re-fetches the playlist/EPG immediately, no restart needed.
- Settings persist to `%AppData%\EyePeeOnMyTV\settings.json`. On first run (no file yet), the
  fields are pre-populated with this app's original hardcoded M3U/EPG URLs so behavior is
  unchanged until you edit them.

## Project layout

- `Models/Channel.cs`, `Models/EpgProgramme.cs`, `Models/AppSettings.cs` — data models
- `Services/M3uParser.cs` — extended M3U playlist parser (tolerant of missing attributes)
- `Services/EpgParser.cs` — streaming XMLTV parser + now/next lookup
- `Services/DataSourceService.cs` — fetches the playlist/EPG URL(s) from `AppSettings`
- `Services/SettingsService.cs` — loads/saves `AppSettings` as JSON under `%AppData%\EyePeeOnMyTV`
- `MainWindow.xaml(.cs)` — dark, chrome-minimal player UI: menu bar, video surface, overlays,
  control bar, collapsible channel sidebar
- `Dialogs/` — menu-bar tool windows: `SettingsWindow`, `EqualizerWindow`, `VideoAdjustmentsWindow`,
  `MediaInfoWindow`, `MessagesWindow`, `AboutWindow`, `ShortcutsWindow`, and a reusable `InputDialog`
  (used for Open Network Stream)

## Notes on scope (v1)

- No recording/DVR/timeshift, no multi-playlist support, no transcoding, no full EPG grid.
- The EPG overlay shows only "Now" / "Next" for the currently playing channel, refreshed every 60 seconds.
- On stream drop, playback retries automatically (a few attempts with backoff) before showing an error state.
- The M3U/EPG fetch runs off the UI thread on startup so the window stays responsive while a loading
  indicator is shown.
